MAVEN - BUILD AND DEPENDENCY MANAGEMENT

Apache Maven is a build automation and dependency management
tool commonly used for Java projects.

Maven helps developers manage project dependencies, compile
source code, run tests, package applications, and perform
other build-related tasks.

POM.XML

The pom.xml file is the main configuration file of a Maven
project.

POM stands for Project Object Model.

It contains information such as:

- Project details
- Dependencies
- Plugins
- Build configuration
- Maven properties

DEPENDENCY

A dependency is an external library required by an application.

For example, a Java project may need JUnit for unit testing.

Dependencies are declared inside the dependencies section
of pom.xml.

Example:

<dependency>
    <groupId>org.junit.jupiter</groupId>
    <artifactId>junit-jupiter</artifactId>
    <version>5.10.0</version>
    <scope>test</scope>
</dependency>

GROUP ID

The groupId identifies the organization or group that
provides the project or dependency.

ARTIFACT ID

The artifactId identifies the specific library or project.

VERSION

The version specifies which release of the dependency
should be used.

MAVEN REPOSITORY

Maven repositories store project dependencies and other
artifacts.

Maven can download required dependencies from remote
repositories such as Maven Central.

MAVEN LIFECYCLE

Maven provides predefined build lifecycles.

The commonly used lifecycle phases include:

validate
Validates the project configuration.

compile
Compiles the source code.

test
Runs unit tests.

package
Packages the compiled code into an artifact such as a JAR.

verify
Performs checks on the results of integration tests.

install
Installs the packaged artifact into the local Maven repository.

deploy
Copies the packaged artifact to a remote repository.

COMMON MAVEN COMMANDS

mvn clean

Removes files generated by previous builds.

mvn compile

Compiles the project source code.

mvn test

Compiles and runs the tests.

mvn package

Builds and packages the application.

mvn clean install

Cleans the previous build, builds the project, runs tests,
and installs the generated artifact into the local repository.

MAVEN PLUGINS

Maven plugins provide additional functionality during the
build process.

For example, plugins can be used for:

- Compiling Java code
- Running tests
- Creating JAR files
- Generating reports
- Performing code quality checks

Maven is commonly used with Spring Boot, JUnit, Selenium,
and other Java-based projects.

In a software testing project, Maven can manage testing
dependencies and execute automated tests as part of the
build process.
